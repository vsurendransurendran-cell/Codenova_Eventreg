🎟️ EVENTFLOW – Event Registration Platform

EVENTFLOW is a web application that helps users discover events and register online. Administrators can create events and manage registrations.

✨ Features

- 🔍 Search and filter events
- 📝 Register for events online
- 📅 View event details
- 🔐 Admin login
- ⚙️ Create, edit, and delete events
- 👥 Manage event registrations
- 📊 Export registration details as CSV

🛠️ Technologies Used

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Tools: Vite, Git, GitHub

🚀 How to Run

1. Clone the repository:
   
   git clone https://github.com/vsurendransurendran-cell/Codenova_Event.git

2. Open the project folder:
   
   cd Codenova_Event

3. Install dependencies:
   
   npm install

4. Start the application:
   
   npm run dev

🎯 Project Objective

To make event discovery, registration, and management simple and convenient for both users and administrators.
